AgroSelect — Brand Identity

The visual system behind AgroSelect, a decision-support tool that helps smallholder farmers compare crops and inputs by cost, expected yield, and market value. Everything here matches what's used in the live landing page.

Logo

Mark and lockups

The mark is four diagonal bands running through the full palette in order — a compressed reading of plowed field rows, the same motif used as the landing page's hero graphic. It never needs to be redrawn in a single color; the four-color version is the primary and only form.

Color

Palette

Deep Green carries headlines, navigation, and primary text. Mid Green is the workhorse for buttons and links. Lime is reserved for one job only: flagging the best option in a comparison. Yellow is a small accent, used sparingly. Paper is the base background, never pure white.

Typography

Type system

Two families, two jobs. Space Grotesk carries headlines and data — anything that should read like a figure or a decision. Inter carries everything a person reads at length.

Usage

Keeping it consistent

Do

  • Use the full four-color mark at every size down to 24px
  • Keep Lime reserved for flagging the best option in a comparison
  • Set headlines in Space Grotesk, body copy in Inter
  • Use the dark-background lockup only on Deep Green, never on photos

Don't

  • Recolor the mark to a single flat color
  • Use Lime or Yellow as a body text color
  • Stretch or skew the mark's proportions
  • Pair Space Grotesk headlines with a third font family
